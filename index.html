Same AI, Different Blind Spots

Where VAT and US sales tax differ, and where AI cannot do the work
VAT US sales tax
Tax determination complexity Where the transaction takes place: detailed place-of-supply rules Where the customer is: which state, county, city and district apply
Tax reporting complexity Multiple returns and listings, mandatory e-invoicing in many countries State-specific return formats; local jurisdiction codes; home‑rule local filings
AI limitations Generating e-invoices; mapping transactions to return boxes The jurisdiction and rate lookup

In both: AI helps with research and reasoning over the law

The App Is Not the Model

  • The model knows only what you put in front of it
  • Memory, projects, custom instructions, connectors: those are app layers
  • Connect your Drive or folders; skip the upload
  • Connected ≠ read

Match the Model to the Task

Flagship

Highest performance, for the hardest reasoning. Expensive, and often slower.

For tax work

Workhorse

Balanced capability, price, and speed. About 80% of day-to-day work.

Light

Small, fast, and cheap. Bulk processing, automations, and sub-agents.

Turn reasoning up to analyse, down to draft. The newest model is rarely the right one.

How Does Web Search Work?

  • Search is a tool, not a model capability
  • It returns a few results and snippets, not the web
  • Fetching a page is a separate, optional step
  • The model reasons over what came back
  • A pasted URL isn't necessarily a read page

What Is an Agent?

  • Chat answers a question. An agent works toward a goal.
  • It loops: plan, act, check, repeat
  • A different path, sometimes a different answer, each run
  • A skill is its operating manual for a specific job

Not Everything Needs an Agent

Workflow

Fixed steps, every time. Breaks on exceptions.

AI workflow

One step uses AI. Stays auditable.

Agentic workflow

One step handed to an agent. Autonomy inside a fence.

Agent

A goal, not a path. A different route each run.

The more autonomy, the more human review.

Three Questions Before
You Build an Agent

Three questions that decide between an agent and a workflow
Yes → an agent may help No → build a workflow
Is the task interpretation-heavy? Taxability research for a new product Applying a known rate; filing a return
Can you live with a different answer each run? A research summary for review A return figure or a tax calculation
Do the edge cases outnumber the rules? Spotting anomalies across millions of transactions Classifying a sale as intrastate, interstate or international by ship-from and ship-to

What to Do on Monday

  • Use AI to reason; use a tax engine for the rate
  • Know what the model actually saw
  • Put AI on the one hard step, and a human after it
